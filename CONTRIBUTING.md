# Contributing

Small, reproducible improvements are welcome. Open an issue describing the problem, expected behavior, platform, and a minimal example. For a change, include the relevant test results and describe remaining limitations.

Use synthetic or explicitly redistributable fixtures. Do not upload private recordings, access tokens, signing profiles, or proprietary model weights. New performance claims need an input description, baseline, configuration, hardware, and a repeatable measurement procedure.

See README.md for setup and docs/VALIDATION.md for the verification boundary.
