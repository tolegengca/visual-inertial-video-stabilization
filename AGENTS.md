# Contributor and agent guide

Read README.md and docs/VALIDATION.md before changing code or making capability claims.
Keep experiments reproducible. Distinguish synthetic tests, recorded results, and hardware validation.
Never commit secrets, personal recordings, device profiles, derived build products, or local databases.
Run the documented tests for the affected component. Do not invent benchmark numbers or mark untested features as verified.
Keep implementation, public documentation, and supported interfaces consistent.
